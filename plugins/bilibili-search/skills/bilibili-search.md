# B 站视频搜索

## 何时使用

用户想找视频、想看某个主题/教程/UP 主在 B 站的内容、或让你推荐视频时，调用 `bilibili_search_videos` 工具。

## 如何调用

- `keyword`（必填）：搜索关键词，与 B 站网页搜索框的用法一致。
- `page`（可选）：页码，默认 1。结果不够或用户想看更多时翻页。

## 如何呈现结果

- **界面会在工具调用条目处自动渲染视频卡片网格**（数据来自工具结果中的 ` ```bilibili-card ` 代码块），你**不需要**复制该代码块到回复，也**不要**自己贴封面图片。
- 你的回复只需：简短的文字总结（如共约多少条、最推荐的 2~3 个及理由），可用「标题 + 链接」列表；推荐理由可引用播放量/时长等数据。
- 结果太多时提示可翻页（page 参数）或缩小关键词。
- 用户明确要求极简输出时，只给一句话加链接列表。
- 没有结果就如实说明，并建议换关键词。

## 约束

- **不要编造视频信息**（标题、UP 主、数据一律来自工具返回）。
- 该工具是受限（restricted）工具：会话内首次调用需要用户确认，这是预期行为。
- B 站偶发风控（HTTP 412）：搜索失败时向用户说明，建议稍后重试，不要连续快速重试。
